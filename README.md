# Real Time Graphics Programming

This repository contains the source code for a real time graphics programming project. It is an old project that I made during my Master's degree in Computer Science.

## Project Overview

The project is a simulation of soft bodies collision using OpenGL as graphics engine and Bullet Physics as physics engine. I'm currently refactoring the project to better reflect my professional work experience in software engineering and the acquired best practices.

- The project is based on C++.
